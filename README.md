
# Java To-Do List Application

A simple console-based To-Do List application developed using Java.
This project allows users to organize their daily activities by
adding, viewing, completing, and deleting tasks.

## Features

- Add new tasks.
- View all tasks.
- Mark tasks as completed.
- Delete tasks.
- Validate user input.
- Simple menu-driven interface.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner

## Requirements

- Java Development Kit (JDK) 8 or later.
- A Java IDE or code editor (such as VS Code or IntelliJ IDEA).

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/todo-list-java.git
```

### 2. Navigate to the project directory

```bash
cd todo-list-java
```

### 3. Compile the Java program

```bash
javac -d out src/ToDoListApp.java
```

### 4. Run the application

```bash
java -cp out ToDoListApp
```

## How It Works

When the application starts, users are presented with a menu
containing five options:

1. Add Task
2. View Tasks
3. Mark Task as Completed
4. Delete Task
5. Exit

Users can select an option by entering its corresponding number.
